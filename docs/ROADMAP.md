# TrashWatch — Roadmap

**Version:** 1.0

---

## Post-v1 Extensions

| Feature | Effort | Notes |
|---------|--------|-------|
| **7-Bag Randomizer** | Low | Replace simple random |
| **Hold Piece** | Low | C key, swap with next |
| **SRS + Wall Kicks** | High | Full Guideline compliance |
| **Multi-Room Support** | Medium | Room list, create/join UI |
| **Replay System** | Medium | Record inputs, playback |
| **High Scores** | Low | Persist to file/Redis |
| **Mobile Touch Controls** | Medium | Virtual buttons for spectator play |
| **TETR.IO Bot API** | High | Compatible protocol |
| **Tournament Mode** | High | Multiple players, synchronized |
| **Custom Themes** | Low | CSS variables for browser, ANSI for terminal |

---

## Priority for v1.1

1. **7-Bag Randomizer** — Fair piece distribution
2. **Hold Piece** — Standard modern Tetris feature
3. **High Scores** — Local file persistence
4. **Custom Themes** — Terminal color schemes, browser CSS themes

---

## Priority for v2.0

1. **Multi-Room Support** — Multiple concurrent games
2. **Replay System** — Share/analyze games
3. **SRS + Wall Kicks** — Guideline compliance

---

## Long-term Vision

- **Tournament Mode** — Bracket play, synchronized seeds
- **TETR.IO Compatibility** — Cross-platform play
- **Mobile App** — Native spectator/player experience
